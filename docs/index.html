    사용 방법

    1. 카메라 시작을 누르고 카메라 권한을 허용하세요.
    2. 오른쪽 목록의 제스처를 손으로 해 보세요. 확률이 70%를 넘으면 초록색으로 표시되고 손에서 이모지가 날아갑니다.

    나만의 제스처 만들기

    이 페이지의 모델은 Python으로 직접 녹화·학습한 것입니다. 저장소에서 내 제스처를 학습시켜 바꿀 수 있습니다.

    1. python collect_gestures.py v ok — 녹화하고 이모지 연결
    2. python train_gestures.py — 학습
    3. python export_web_model.py — 웹용 모델(docs/gesture_model.json)로 변환 후 푸시
